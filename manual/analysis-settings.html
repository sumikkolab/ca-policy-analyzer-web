分析設定とは

左サイドバーの「分析設定」セクションでは、ギャップ分析（推奨構成との比較）でポリシーを判定するための設定を行います。

主に、管理者グループ名とゲストグループ名を登録します。

管理者グループ名の設定

組織で使用している管理者グループの名前を登録します。

入力欄にグループ名を入力し、Enter キーで画面上の一覧に追加します。この時点では保存されていません。「設定を保存」を押すと保存されます。

複数のグループ名を登録できます（例: Global Admins, IT Administrators, Security Admins）。

保存した設定は、以下の機能で使われます:

  • ギャップ分析: 管理者向けの推奨項目で、登録したグループ名を使って対象のポリシーを判定します。全ユーザー向けのポリシーが管理者グループを除外している場合も検出します。
  • 管理者除外分析: ギャップ分析の結果から、管理者グループを除外しているポリシーを示します。

次の機能では、グループ名の設定を使いません:

  • 管理者保護不備の検出（診断）: ポリシーに指定された管理者ロールと、MFA の要求の有無で判定します。
  • 設計不備の検出（カバレッジ分析）: ポリシー全体を対象に判定します。グループ名の設定は影響しません。

グループ名は、大文字・小文字を区別せず、ポリシー JSON に含まれるグループ名と完全一致するか、一方がもう一方を含む場合に一致と判定されます。短い名前を登録すると、意図しないグループにも一致することがあります。

ゲストユーザーグループ名の設定

ゲストユーザーが所属するグループの名前を登録します。

入力方法は管理者グループ名と同じです。「設定を保存」を押すと保存されます。

保存した設定は、以下の機能で使われます:

  • ギャップ分析: ゲストユーザー向けの推奨項目で、登録したグループ名を使って対象のポリシーを判定します。

エクスポートメタデータ

Excel / PDF エクスポート時に使用される組織情報を設定します。

  • 組織名 / テナント名（必須）
  • テナント ID（推奨）
  • 文書バージョン（デフォルト: 1.0）
  • 作成者（必須）

設定の保存

分析設定は、「設定を保存」を押すと保存されます。自動では保存されません。

「設定を保存」では、管理者グループ名・ゲストユーザーグループ名と、エクスポートメタデータをまとめて保存します。グループ名の入力欄に Enter キーで追加していない文字がある場合は、保存時に一覧へ追加されます。

ギャップ分析は、保存済みの設定を読み込んで実行します。

通常の保存先: %LocalAppData%\CAPolicyAnalyzer\Data\analysis-settings.json

Microsoft Store 版では、Windows により %LocalAppData%\Packages 以下の対応する場所に保存される場合があります。

分析設定を変更した後は、「設定を保存」を押してからギャップ分析を再実行すると、新しい設定が反映されます。

Chapter 10: Analysis Settings

CA Policy Analyzer User Manual

What Are Analysis Settings?

The "Analysis Settings" section in the left sidebar lets you configure how policies are evaluated in the gap analysis (comparison with recommended configurations).

Primarily, you register administrator group names and guest group names.

Administrator Group Name Settings

Register the names of administrator groups used in your organization.

Type a group name in the input field and press Enter to add it to the list on the screen. It is not saved at this point. Select "Save Settings" to save it.

Multiple group names can be registered (e.g., Global Admins, IT Administrators, Security Admins).

The saved settings are used by the following features:

  • Gap Analysis: For recommended items aimed at administrators, the registered group names are used to determine which policies apply. It also detects all-user policies that exclude an administrator group.
  • Admin Exclusion Analysis: Based on the gap analysis results, shows the policies that exclude an administrator group.

The following features do not use the group name settings:

  • Administrator Protection Gap Detection (diagnostics): Determined from the administrator roles specified in policies and whether MFA is required.
  • Design Flaw Detection (coverage analysis): Evaluated across all policies. The group name settings have no effect.

Group names are matched without regard to case. A name matches a group name in the policy JSON if the two are identical or if one contains the other. A short name may therefore match groups you did not intend.

Guest User Group Name Settings

Register the names of groups that guest users belong to.

The input method is the same as for administrator group names. Select "Save Settings" to save them.

The saved settings are used by the following features:

  • Gap Analysis: For recommended items aimed at guest users, the registered group names are used to determine which policies apply.

Export Metadata

Configure organization information used when exporting to Excel or PDF.

  • Organization Name / Tenant Name (required)
  • Tenant ID (recommended)
  • Document Version (default: 1.0)
  • Author (required)

Saving Settings

Analysis settings are saved when you select "Save Settings". They are not saved automatically.

"Save Settings" saves the administrator group names, the guest user group names, and the export metadata together. If a group name input field contains text that you have not added with Enter, it is added to the list when you save.

The gap analysis runs using the saved settings.

Usual save location: %LocalAppData%\CAPolicyAnalyzer\Data\analysis-settings.json

In the Microsoft Store version, Windows may store the data in the corresponding location under %LocalAppData%\Packages.

After changing analysis settings, select "Save Settings" and then re-run the gap analysis to apply the new settings.
