# CA Policy Analyzer

[English README](README.md)

**条件付きアクセスに、管理者の除外やレガシー認証の許可が残っていないか、確認できていますか。**

## このツールについて

CA Policy Analyzer は、Sumikko Lab が開発する Windows デスクトップアプリです。条件付きアクセス ポリシーを分析するツールで、ポリシーの JSON を読み込み、テナントに接続せず PC 内で分析します。ライセンスの確認と購入のために、Microsoft Store に接続します。

## できること

- ギャップ分析: 28 項目の推奨構成(Microsoft 16・DISA STIG 5・NIST SP 800-53 7)と現在のポリシーを比較します。
- 管理者除外分析: 管理者グループの除外が見つかった推奨項目と、管理者専用ポリシーで補えているかを示します。
- カバレッジ分析: ポリシーを組み合わせても残る隙間と、全ユーザー向けポリシーの多くから除外されているグループを示します。ポリシーの除外設定の抜け漏れ確認に使えます。
- 変更履歴: JSON を読み込むときに入力した変更者と変更理由を記録し、差分を確認できます。
- シミュレーション(Pro): ユーザーやアプリなどの条件を指定して、ブロックされるかを確認します。
- Excel 設計書(8 シート)と PDF レポートの出力(Pro): 自動診断の結果(全ユーザー・全アプリをブロックして除外が無いポリシー、競合、重複など)も出力できます。診断を含めるには、出力前に「推奨構成との比較」を実行します。

## できないこと

- テナントからのポリシーの自動取得と、テナントの設定の変更はできません。
- Microsoft Entra 管理センターや Microsoft Graph が出力した JSON は、そのままでは読み込めません。アプリの形式への変換が必要です。形式は[サンプル ファイル](sample-policies-for-review.json)で確認できます。
- シミュレーションでは、デバイスの準拠状態を指定できません。リスクを条件にしたポリシーは「不適用」になります。ロールとデバイス フィルターの条件は評価しません。
- 判定は目安です。各基準の公式な認証や保証ではありません。

## 対象者

条件付きアクセスを設計・点検・報告する Microsoft Entra ID の管理者

## 入手方法

- [Microsoft Store](https://apps.microsoft.com/detail/9NR10PX75754)
- [製品サイト](https://capolanalyzer.sumikkolab.com/) / [ユーザー マニュアル](https://capolanalyzer.sumikkolab.com/manual/) / [サポート](https://capolanalyzer.sumikkolab.com/support.html)

本体は無料で、初回起動から 15 日間試用できます。試用中は、Pro の機能(シミュレーション、Excel・PDF の出力)は使えません。試用後に使い続けるには、Standard または Pro のアドオン(アプリ内購入)が必要です。価格は Microsoft Store で確認してください。

動作環境: Windows 10 バージョン 2004 以降 / Windows 11(x64)、WebView2 Runtime。表示言語は日本語と英語です。
